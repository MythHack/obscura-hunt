# Spec Delta

## Purpose

规定通过浏览器公开 PDF 导出接口得到的文档内容质量：真实文字必须可选择、搜索和提取，字体必须随文件嵌入，适合矢量表示的内容不得被整页 JPEG 替代。同时保留现有打印媒体、分页、纸张、缩放、页范围、背景和有界输出行为，不能把提高截图分辨率误称为本项文字与矢量导出完成。

## ADDED Requirements

### Requirement: RC-25 矢量和文字 PDF

浏览器 SHALL 通过 Page.printToPDF、MCP browser_pdf 及嵌入式 PDF 导出消费者提供包含真实文字、嵌入字体和适用矢量图形的 PDF，使文字可选择、复制、搜索及 Unicode 提取；原有打印媒体、分页、选页、缩放和资源边界必须保留，不能以整页放大栅格、不可见伪文字层或空字体对象代替实际内容，也不能把本能力宣称为已实现 tagged PDF/PDF-A。

#### Scenario: 真实文本文档包含可提取文字和嵌入字体

- **WHEN** 消费者导出固定字体的 `Hello` 标题、`RM 6,000.00` 正文及包含重音字符、中文和所选字体支持的 shaping 文本的本地文档，并用独立 PDF 阅读器、字体检查器和文本提取器打开结果。
- **THEN** 页面可见文字由真实文字内容绘出，读者能够选择、复制和搜索，提取器获得对应 Unicode 文本；字体检查显示实际使用字体已嵌入并按使用字形进行有效子集化，字形与文字映射正确，不因连字或 fallback 丢失正文，不是仅显示一张背景图。

#### Scenario: 文字与矢量保持放大质量

- **WHEN** 本地夹具还包含边框、实心/描边路径及 SVG 矢量形状，分别导出 scale=1 和 scale=2，在阅读器中高倍放大并检查内容对象。
- **THEN** 适合矢量表示的线条、形状与文字保留真实矢量/字体表示，缩放改变相应几何而非继续放大固定 800px 页面截图；文字与形状的可见位置、大小、颜色和裁剪相符，不能以单一 JPEG 加不可见文字覆盖层取得提取成功。

#### Scenario: 图片与 Live Canvas 可与矢量内容共存

- **WHEN** 夹具混合普通图像、当前 Canvas 像素、可导出的文字及矢量形状，并以 print-media 专用样式导出。
- **THEN** 固有栅格内容可以作为局部图像保留，文字与矢量仍保持各自真实表示，图层顺序、alpha 和 print 样式一致；不能因为一张图片或一个 Canvas 就把整页内容栅格化，也不能为了无栅格统计而丢掉应有图像。

#### Scenario: 现有分页与打印选项不因编码切换退化

- **WHEN** 导出多页受控文档，设置纸张尺寸、方向、margin、printBackground、scale 与不连续/重叠 pageRanges，并包含固定内容及不同 screen/print 样式。
- **THEN** PDF 的页数、MediaBox、内容分页和打印媒体保持对应选项语义，所选页按文档顺序每页输出一次，固定内容在适用页正确出现，正文按页前进且不会重复或遗漏；背景开关及缩放对矢量与局部栅格一致生效，不新增未承诺的完整 CSS paged-media 能力。

#### Scenario: 各公开出口交付等价的真实 PDF

- **WHEN** CDP 客户端分别使用 ReturnAsBase64 与 ReturnAsStream/IO.read，MCP 客户端读取 browser_pdf 的 application/pdf 资源，嵌入式调用者导出同一文档。
- **THEN** 各出口得到可独立打开并具有同等文字、字体与图形语义的有效 PDF，stream 能完整读取和关闭，输出能力标识与实际编码一致；不能只改一个 CDP 返回值而留下其他消费者继续输出 raster-only 文档。

#### Scenario: 无效输入与资源上限诚实失败

- **WHEN** 输入非法尺寸、margin、scale、页范围，页面不可渲染，导出超过既有页数/输出/资源安全边界，或请求尚未支持的 CSS @page、页眉页脚、文档大纲或标签能力。
- **THEN** 保留明确的参数、能力或资源错误及现有真实能力披露，不输出截断却看似有效的 PDF，不静默回退整页 JPEG，不移除 watchdog、取消、字体/图片来源权限或输出上限；无 render 构建仍明确报告导出不可用，不伪造空白成功文件。
